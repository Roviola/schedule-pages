# 你的日程工作台

> AI 驱动的个人日程管理工具 — 从日历规划到习惯打卡，从目标拆解到灵感收集，一个工作台搞定。

[在线体验](https://Roviola.github.io/schedule-pages/wellness-planner/)

---

## 功能

### 📅 日历
月/周/日三种视图灵活切换，工作、生活、学习、健康、社交五色分类一目了然。

### ✅ 日常记录
习惯打卡 + 文字记录 + 图片上传，时间线回顾每一天的进展，页面底部自动生成今日总结。

### 🎯 目标管理
长期目标与短期目标分开，每个目标拆成子任务，填写"为什么重要""怎么衡量""第一步做什么""潜在风险"，进度条实时更新。

### 💡 灵感收集
卡片墙展示 AI 工作流、宣传文案、视觉灵感和产品灵感，支持分类筛选、收藏、图片上传。

### ☁ 多端同步
登录后电脑和手机数据自动同步，不登录则纯本地使用，数据不上传。

---

## 技术栈

- 纯前端：HTML + CSS + JavaScript 单页应用
- 数据存储：localStorage（本地） + Supabase（云同步）
- 部署：GitHub Pages

## AI 协作

在 AI 辅助下完成了产品定位、信息架构设计、模块开发、样式调整和响应式适配。分阶段推进：先确定用户场景和功能优先级，再按日历、日常、目标、灵感四个模块逐个实现，每种视图、每个交互都在验证后才进入下一阶段。
